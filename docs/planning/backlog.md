## XL 任务拆片顺序

- SM-005：平台身份/句柄 → 认证 IPC 与账本 → spawn 故障核实 → IO 预算 → 服务安装模式。
- SM-006：启动持久意图 → 停止/maintenance → 对账 → 有界自动恢复；每片都保持不双启。
- SM-009：只读 Inspect → 安全暂存 → 安装计划提交 → CopyManaged → AttachInPlace；默认不执行导入脚本。
- SM-010：Daemon+CLI 消费 → Presentation → OOBE/列表 → 实例/操作 → 控制台 → 真 Provider 桌面验收。
- SM-012：卷互斥模型 → 停服备份 → manifest → 恢复切换与崩溃 → 保留/GC → 计划任务；在线静默备份另加验证切片。
- SM-013/014：身份配对 → 请求 API → 状态订阅 → 吊销/限额 → Web → 服务升级 → 控制权转移。
- SM-015/017：资源预留 → fencing → 冷迁移 → Fleet 固定容量 → Sessions → 路由隔离 → 灰度；不得以缓存决定最终容量。
- SM-018：先定义 HA 故障模型/数据库模式，再迁移与恢复，最后按实测扩展容量；不是一次 PR 全部完成。
